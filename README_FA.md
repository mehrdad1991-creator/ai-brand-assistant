## معرفی

«دستیار برندسازی هوش مصنوعی» یک اپلیکیشن وب کامل است که از یک توضیح ساده دربارهٔ کسب‌وکار، یک کیت کامل برندسازی تولید می‌کند.

کافی است توضیحی مانند «یک کافه قهوهٔ تخصصی و ارگانیک در تهران که هدفش جوانان حرفه‌ای است» وارد کنید تا در ۲۰ تا ۳۰ ثانیه دریافت کنید:

- **طرح لوگوی تولیدشده با هوش مصنوعی**
- **۳ پیشنهاد نام برند**
- **۳ شعار تبلیغاتی**
- **یک متن آمادهٔ شبکه‌های اجتماعی**
- **پالت رنگ پنج‌رنگ با کدهای هگز**
- **پیشنهاد ترکیب فونت**
- **پروفایل مخاطب هدف**

این ابزار از **ورودی فارسی و انگلیسی** پشتیبانی می‌کند و زبان خروجی را به‌طور خودکار با زبان ورودی هماهنگ می‌کند.

## ویژگی‌ها

| ویژگی | توضیح |
| :--- | :--- |
| **تولید متن** | نام برند، شعار، متن شبکه‌های اجتماعی، پروفایل مخاطب |
| **تولید تصویر** | لوگوی تولیدشده بر اساس نخستین نام برند |

| **فارسی و انگلیسی** | پشتیبانی کامل دوزبانه با تشخیص خودکار زبان |
| **رابط کاربری مدرن** | طراحی تمیز و واکنش‌گرا با Tailwind CSS |
| **کپی و دانلود** | کپی متن با یک کلیک و دانلود کل کیت به‌صورت JSON |

## پشتهٔ فناوری

| لایه | فناوری |
| :--- | :--- |
| **بک‌اند** | Python 3.14, FastAPI, Uvicorn |
| **کلاینت هوش مصنوعی** | OpenAI Python SDK (سازگار با OpenAI) |
| **درگاه هوش مصنوعی** | AvalAI (در دسترس از ایران، سازگار با OpenAI) |
| **مدل متنی** | GPT-4o (یا معادل آن) |
| **مدل تصویری** | `gpt-image-2.5-flare` (از طریق AvalAI) |
| **فرانت‌اند** | HTML5, Tailwind CSS (از طریق CDN), JavaScript خالص |
| **ابزار توسعه** | Cursor, Claude, VS Code |
| **محیط اجرا** | آماده برای Docker، پیکربندی با فایل `.env` |
